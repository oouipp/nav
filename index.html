首次使用？点这里看 Token 创建步骤
  1. 打开 GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access 选择 Only select repositories，勾选本导航仓库
  3. Repository permissions → Contents 设为 Read and write
  4. 生成后复制 github_pat_... 粘贴到上方输入框

Token 仅保存在当前浏览器的 localStorage，不会提交到仓库。公共仓库的读取不需要 Token，只有写入才需要。

检测到数据冲突

云端仓库和本机的数据都被修改过，请选择保留哪一份：

  • 使用云端：放弃本机改动，以仓库中的最新数据为准
  • 使用本机：用本机数据覆盖仓库
  • 合并两者：保留双方所有按钮（推荐）
